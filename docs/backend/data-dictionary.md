## Classification

| Class | Meaning | Handling |
|---|---|---|
| **public** | May be returned to an anonymous caller, for example on an active listing. | Exposed only through a DTO mapper that lists the field by name. |
| **private** | Visible only to the owner or a conversation participant, or used by the server only. | Exposed only in owner/participant DTOs, after a query filtered by owner or participant. Not returned to other users (404 policy, see `api-conventions.md`). |
| **secret** | Credential material. | Exposed by no DTO, never logged, read only by the auth code that verifies it. |

A field's class can depend on the row state: the fields of a `Product` marked public are public only while `status = ACTIVE`. A `REMOVED` listing is private to its seller.

| DTO | Status | Mapper / OpenAPI schema | Fields |
|---|---|---|---|
| `CategoryDto` | implemented | `toCategoryDto` / `Category` | `id`, `label` |
| `PublicSellerDto` | implemented | `toPublicSellerDto` / `PublicSeller` | `id`, `displayName` |
| `ProductDto` | implemented | `toProductDto` / `Product` | `id`, `title`, `description`, `price`, `currency`, `categoryId`, `seller` (PublicSellerDto), `createdAt`, `updatedAt` |
| `OwnProductDto` | planned (Phase 4) | `OwnProduct` | ProductDto fields + `status`, `version` |
| `CurrentUserDto` | planned (Phase 3) | `CurrentUser` | `id`, `email`, `displayName`, `role`, `createdAt` |
| `ConversationDto` | planned (Phase 5) | `Conversation` | `id`, `productId`, `role` (from the session user's participant row), `counterpart` (PublicSellerDto of the other participant), `lastMessageSeq`, `createdAt`, `updatedAt` |
| `MessageDto` | planned (Phase 5) | `Message` | `id`, `conversationId`, `senderId`, `body`, `clientMessageId`, `seq`, `createdAt` |

Token responses (`AccessToken`, `MobileTokens`, `WebSession`, `MobileSession`) carry the access token and, on mobile, the raw refresh token issued to the session owner. They never carry `Session.refreshTokenHash` or any other `Session` column.

Serialization: prices are strings with exactly two decimals (`serializePrice`), dates are ISO 8601 UTC strings.

## Conventions shared by all models

- `id`: `UUID`, primary key, random UUID v4 generated by Prisma (`@default(uuid())`). Opaque, never a permission.
- `createdAt`: `TIMESTAMPTZ(3)`, `NOT NULL DEFAULT CURRENT_TIMESTAMP`.
- `updatedAt`: `TIMESTAMPTZ(3)`, `NOT NULL`, set by Prisma on every write (`@updatedAt`); no database default.
- Every foreign key is `ON DELETE RESTRICT ON UPDATE RESTRICT`: deleting a parent that still has children fails instead of cascading.
- `VARCHAR(n)` caps mirror the Zod limits, so the database refuses oversized data if validation is bypassed.

## Session

One row per refresh token. Rotation creates a new row in the same family and marks the previous one used; presenting a used token again revokes the whole family. No `Session` column is exposed by any DTO.

| Field | Type | Constraints | Class | Exposed by |
|---|---|---|---|---|
| `id` | `UUID` | PK | private | none (carried inside the signed access token as a claim, not in a DTO) |
| `userId` | `UUID` | `NOT NULL`, FK `Session_userId_fkey` → `User.id` | private | none |
| `refreshTokenHash` | `VARCHAR(128)` | `NOT NULL`, unique (`Session_refreshTokenHash_key`). Digest of the opaque refresh token; the token itself is never stored. | **secret** | none |
| `familyId` | `UUID` | `NOT NULL`. Shared by all sessions rotated from one login. | private | none |
| `expiresAt` | `TIMESTAMPTZ(3)` | `NOT NULL` | private | none |
| `revokedAt` | `TIMESTAMPTZ(3)` | nullable | private | none |
| `usedAt` | `TIMESTAMPTZ(3)` | nullable. Set when the token is rotated; a later presentation is a reuse. | private | none |
| `replacedById` | `UUID` | nullable, unique (`Session_replacedById_key`), FK `Session_replacedById_fkey` → `Session.id` | private | none |
| `createdAt` | `TIMESTAMPTZ(3)` | see conventions | private | none |
| `updatedAt` | `TIMESTAMPTZ(3)` | see conventions | private | none |

Indexes: `Session_userId_expiresAt_idx (userId, expiresAt)`, `Session_familyId_idx (familyId)`, `Session_expiresAt_idx (expiresAt)`.

A message in a conversation. Private to the two participants. An `ADMIN` role gives no access to messages.

| Field | Type | Constraints | Class | Exposed by |
|---|---|---|---|---|
| `id` | `UUID` | PK | private | `MessageDto.id` |

| `senderId` | `UUID` | `NOT NULL`, FK `Message_senderId_fkey` → `User.id`. Taken from the session, never from the payload. | private | `MessageDto.senderId` |
| `body` | `VARCHAR(2000)` | `NOT NULL`; CHECK `Message_body_not_blank_check`: `btrim(body) <> ''`. Never logged. | private | `MessageDto.body` |

## Secret fields summary

| Field | Stored as | Exposed by | Logged |
|---|---|---|---|
| `User.passwordHash` | Argon2id encoded hash | no DTO | never (redacted key `passwordHash`) |
| `Session.refreshTokenHash` | digest of the refresh token | no DTO | must never be passed to the logger. The key is **not** in `SECRET_KEYS` today, so redaction does not catch it. |

The plaintext password and the plaintext refresh token are never stored. They exist only in request bodies (`writeOnly` in OpenAPI), the refresh cookie and the mobile token responses.

Log redaction (`backend/src/infrastructure/logger.ts`): `SECRET_KEYS` redacts `password`, `passwordHash`, `token`, `accessToken`, `refreshToken`, `cookie` and `authorization` at any depth (case-insensitive), and `REDACT_PATHS` removes the `authorization`, `cookie` and `x-csrf-token` request headers and the `set-cookie` response header. Message bodies are kept out of logs by not logging request bodies, not by redaction.
